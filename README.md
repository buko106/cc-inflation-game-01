# インフレ造幣局

お金を刷って、刷って、刷りまくる。ハイパーインフレがテーマの放置系インフレゲームです。
10円から始めて、最後は 1e3000 円 (ゼロが3000個並ぶ額面) を目指します。

ビルド不要。`index.html` をブラウザで開くだけで遊べます。

## 遊び方

1. **造幣機を買う** — 輪転機はお札を刷り、印刷工場は輪転機を、造幣局は印刷工場を…と、上の段が下の段を増やしていきます。同じ造幣機を10台そろえるたびに倍率 ×2。
2. **印刷速度** — 全造幣機の速度を上げます。
3. **量的緩和** — 最上段を20台そろえると実施できます。資産はリセットされますが、次の造幣機 (最大8段) が解放され、全体の倍率が上がります。
4. **デノミ** — 資産が 100穣円 (1e30円) を超えると、お札のゼロを消して出直せます。消したゼロは「ゼロ」になり、強化や自動化に使えます。
5. **金本位制** — 資産が JavaScript の `Number.MAX_VALUE` (約1.8e308) を超えると、円を捨てて金に戻れます。金塊で全造幣機を大きく強化できます。
6. **インフレの果て** — 1e3000 円でエンディング。その後も刷り続けられます。

ほかに、資産に合わせて上がる「今日の物価」(パン1斤の値段)、実績24個、ニュースティッカー、留守中の進行 (最大24時間)、セーブの書き出し/読み込みがあります。

数字は日本式 (万・億・兆…無量大数) / 指数 / 工学 表記から選べます。

### キーボード

| キー | 操作 |
| --- | --- |
| `1`〜`8` | その段を10台まで買う |
| `Shift`+`1`〜`8` | その段を1台買う |
| `M` | 全部買う |
| `T` | 印刷速度を上げる |
| `Q` | 量的緩和 |
| `D` | デノミ |
| `G` | 金本位制 |

## 開発

```sh
npm test        # Node 18 以上。依存パッケージなし
```

| ファイル | 役割 |
| --- | --- |
| `js/decimal.js` | 1.8e308 を超える巨大数 (仮数 × 10^指数) |
| `js/format.js` | 数字の表記 |
| `js/data.js` | 造幣機・強化・実績・ニュースなどの定数。バランス調整はここ |
| `js/game.js` | ゲームのロジック (DOM に触らない) |
| `js/ui.js` | 画面の組み立てと更新 |
| `js/main.js` | 起動、ゲームループ、保存 |

`<script type="module">` を使っていないので、`file://` で直接開いても動きます。
セーブはブラウザの `localStorage` に10秒ごとに保存されます。

### バランスの目安

自動化をすべて使うボットで試算した到達時間です (人が遊ぶともう少しかかります)。

| 到達点 | 時間 |
| --- | --- |
| 最初のデノミ (1e30円) | 約4分 |
| 金本位制 (1.8e308円) | 約13分 |
| 1e1000円 | 約45分 |
| インフレの果て (1e3000円) | 約65〜80分 |
