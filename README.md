# インフレ造幣局

お金を刷って、刷って、刷りまくる。ハイパーインフレがテーマの放置系インフレゲームです。
10円から始めて、最後は 1e3000 円 (ゼロが3000個並ぶ額面) を目指します。

**遊ぶ:** https://www.buko106.tokyo/cc-inflation-game-01/


## 遊び方

1. **造幣機を買う** — 輪転機はお札を刷り、印刷工場は輪転機を、造幣局は印刷工場を…と、上の段が下の段を増やしていきます。同じ造幣機を10台そろえるたびに倍率 ×2。
2. **印刷速度** — 全造幣機の速度を上げます。
3. **量的緩和** — 最上段を20台そろえると実施できます。資産はリセットされますが、次の造幣機 (最大8段) が解放され、全体の倍率が上がります。
4. **デノミ** — 資産が 100穣円 (1e30円) を超えると、お札のゼロを消して出直せます。消したゼロは「ゼロ」になり、強化や自動化に使えます。
5. **金本位制** — 資産が JavaScript の `Number.MAX_VALUE` (約1.8e308) を超えると、円を捨てて金に戻れます。金塊で全造幣機を大きく強化できます。
6. **インフレの果て** — 1e3000 円でエンディング。その後も刷り続けられます。
   エンディング後は、毎秒の生産が 1e3000 円を超えた分に「インフレ抑制」がかかります (超えた桁数が0.8乗になる)。

ほかに、資産に合わせて上がる「今日の物価」(パン1斤の値段)、実績24個、ニュースティッカー、留守中の進行 (最大24時間)、セーブの書き出し/読み込みがあります。

数字は日本式 (万・億・兆…無量大数) / 指数 / 工学 表記から選べます。

### キーボード

| キー | 操作 |
| --- | --- |
| `1`〜`8` | その段を10台まで買う |
| `Shift`+`1`〜`8` | その段を1台買う |
| `M` | 全部買う |
| `T` | 印刷速度を上げる |
| `Q` | 量的緩和 |
| `D` | デノミ |
| `G` | 金本位制 |

## 開発

Node 22.12 以上が必要です。TypeScript + Vite + Vitest で作っています。

```sh
npm install
npm run dev        # 開発サーバー (保存すると即座に反映)
npm test           # コアのテスト (Vitest)
npm run typecheck  # 型チェック
npm run build      # dist/ に公開用ファイルを出力
npm run preview    # ビルド結果をローカルで確認
```

### 構成

ゲームのロジック (`src/core/`) と画面 (`src/ui/`) を分けています。
`src/core/` は DOM・`localStorage`・タイマーに触らない純粋な TypeScript で、テストはここを対象にします。
コアの型チェック (`tsconfig.core.json`) には DOM の型を含めていないので、コアから `document` などに触ると型エラーになります。

| ファイル | 役割 |
| --- | --- |
| `src/core/decimal.ts` | 1.8e308 を超える巨大数 (仮数 × 10^指数) |
| `src/core/format.ts` | 数字の表記 |
| `src/core/data.ts` | 造幣機・強化・実績・ニュースなどの定数。バランス調整はここ |
| `src/core/state.ts` | 状態の型と初期状態 |
| `src/core/production.ts` | 倍率と毎秒の生産量 |
| `src/core/purchase.ts` | 造幣機と印刷速度の購入 |
| `src/core/prestige.ts` | 量的緩和・デノミ・金本位制 |
| `src/core/upgrades.ts` | ゼロ強化・金強化 |
| `src/core/automation.ts` | 自動化 |
| `src/core/simulation.ts` | 時間経過 (`step` / `advance`) |
| `src/core/market.ts` | 物価 |
| `src/core/achievements.ts` | 実績とエンディング |
| `src/core/save.ts` | セーブの書き出し/読み込み |
| `src/core/index.ts` | コアの公開 API (UI とテストはここから読み込む) |
| `src/ui/ui.ts` | 画面の組み立てと更新 |
| `src/main.ts` | 起動、ゲームループ、保存 |
| `src/bot/` | バランス調整 bot (戦略と実行器。コアだけを使う) |
| `scripts/balance.ts` | `npm run balance` の本体 |
| `tests/` | コアのテスト |

セーブはブラウザの `localStorage` に10秒ごとに保存されます。

### デプロイ

`.github/workflows/pages.yml` が GitHub Pages に公開します。

- PR と `main` への push: 型チェック・テスト・ビルド
- `main` への push のときだけ: ビルド結果 (`dist/`) を GitHub Pages へデプロイ

Actions タブの「Run workflow」から手動でも実行できます。

### バランス調整 bot

`npm run balance` で、コアを早送りして戦略ごとの到達時間を表にします。DOM を使わないので数秒で終わります。

```sh
npm run balance                        # すべての戦略
npm run balance -- active casual       # 戦略を選ぶ
npm run balance -- --max 3h --dt 0.1   # 上限時間 (既定 2h) と1ステップの秒数 (既定 0.05)
npm run balance -- --list              # 戦略の一覧
```

| 戦略 | 遊び方 |
| --- | --- |
| `active` | 毎ティック操作し、ゼロ・金塊の累計が倍になるまで待ってリセット。自動化も買う |
| `normal` | 1秒に1回操作する、ふつうに画面に張りついている人。リセットの判断は `active` と同じ |
| `rush` | 毎ティック操作し、デノミ・金本位制はできたらすぐする |
| `casual` | 10秒に1回操作する。リセットは累計が倍になるまで待つ |
| `idle` | 1分に1回だけ操作する。自動デノミを買ったらデノミはそれにまかせる |
| `no-automation` | 自動化を一切買わず、1秒に1回手で操作する |

戦略は `src/bot/strategy.ts` の `STRATEGIES` に足せます。到達点は `src/bot/run.ts` の `MILESTONES` です。
